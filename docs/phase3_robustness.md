# Phase 3: robustness and calibration

## Questions

Phase 3 tests whether the Phase 2 conclusion survives reasonable analysis choices. The outer test
unit remains one completely unseen subject. No threshold, feature set, calibrator, or hyperparameter
is selected using that subject.

## Artifact-threshold sensitivity

| Threshold | Retained alert/drowsy | Logistic balanced accuracy | RF balanced accuracy |
|---|---:|---:|---:|
| No additional rejection | 1011 / 1011 | 0.635 | **0.685** |
| 1000 µV | 1003 / 997 | 0.658 | 0.682 |
| 500 µV | 997 / 968 | 0.652 | 0.678 |
| 200 µV | 959 / 908 | 0.675 | **0.685** |

The random forest changes by less than 0.008 across conditions. Logistic regression improves when
stricter rejection changes the class composition, especially at 200 µV. Since the artifact was
already author-processed and no external criterion validates these thresholds, the balanced
no-rejection condition remains primary.

## Feature ablation

| Feature group | Count | Logistic balanced accuracy | RF balanced accuracy |
|---|---:|---:|---:|
| Relative band powers | 4 | 0.616 | 0.584 |
| Fatigue ratios | 2 | 0.608 | 0.567 |
| Spectral core | 7 | 0.615 | 0.610 |
| All features | 10 | **0.635** | **0.685** |

The nonlinear model benefits from the complete combination, including spatial dispersion and RMS.
This does not establish physiological causality: channel names are unavailable, and amplitude can
contain acquisition or residual-artifact information.

## Subject-level uncertainty

| Model | Mean | Subject-bootstrap 95% interval | Exact sign-flip p vs 0.5 |
|---|---:|---:|---:|
| Logistic regression | 0.635 | [0.578, 0.693] | 0.00195 |
| Random forest | 0.685 | [0.629, 0.746] | 0.00098 |

The unit of resampling and permutation is the subject-fold score, never an individual window. The
tests remain descriptive for this 11-person selected dataset.

## Cross-fitted probability calibration

| Output | Brier loss | Log loss | ECE |
|---|---:|---:|---:|
| Raw random forest | 0.2102 | 0.6150 | 0.1571 |
| Training-OOF Platt mapping | **0.2092** | **0.6082** | **0.1445** |

Each outer fold builds grouped OOF predictions from only its ten training subjects, fits a sigmoid
mapping, refits the random forest on all ten, and then evaluates the eleventh. Aggregate changes are
small and individual folds sometimes worsen, so the result is evidence of modest average correction,
not operationally trustworthy confidence.

## Nested logistic tuning

Inner five-fold subject-grouped selection considers `C` values 0.01, 0.1, 1, 10, and 100. Selected
values vary across outer folds, and nested balanced accuracy is 0.619 ± 0.090 versus 0.635 ± 0.099
for fixed `C=1`. Tuning therefore adds instability without improving held-out-subject performance.

All CSVs, out-of-fold probabilities, selected parameters, and plot inputs are generated by
`eeg-fatigue-robustness` and retained locally for audit. Generated data remain excluded from Git
until the release-artifact selection stage.
